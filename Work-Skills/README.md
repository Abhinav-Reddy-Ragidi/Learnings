# Work Skills

A living record of skills I can **prove** I have — tied to real work. This is for showcasing capability when taking on a new role or project: I can point to exactly which projects demonstrate which skills.

## Two linked pieces

1. **`SKILLS-MATRIX.md`** — the at-a-glance showcase. Every skill, its category, proficiency, when last used, and a link to the project that proves it.
2. **`projects/`** — one file per real piece of work (the *evidence*). Each describes the problem, my contribution, the outcome, and the skills it demonstrates.

The matrix points at projects; the projects justify the matrix. A skill should not sit above "Practiced" without a project backing it.

## Proficiency scale

| Level | Meaning | Evidence required |
|-------|---------|-------------------|
| **Aware** | Understand the concepts; little/no hands-on | A note or course |
| **Practiced** | Used it on exercises or small tasks, often with guidance | A practice project or guided task |
| **Proficient** | Used it independently to deliver real work | At least one logged work project |
| **Expert** | Deep command; can lead, design, and teach others | Multiple projects, ownership/leadership |

## How I keep it updated
When I tell Claude "I did X at work using Y," it logs the project in `projects/` and updates the skill row in the matrix (level, last-used date, evidence link).

## Excel export
`Skills-Matrix.xlsx` is a shareable snapshot generated from the markdown. Ask Claude to regenerate it anytime the matrix changes (e.g. before an interview).
